À propos

Plus qu'un développeur, un créateur de solutions.

Je suis ADJI KOMENAN Ivan Florian — alias MILANO. Jeune développeur web & mobile et créatif digital basé en Côte d'Ivoire, je me positionne comme un profil polyvalent capable de transformer une idée en solution digitale concrète : site web, application mobile, logiciel, identité visuelle ou contenu digital.

Mon objectif n'est pas simplement de « coder des sites ». Je veux progressivement concevoir des produits numériques complets, de l'idée jusqu'à la mise en production : Idée → Analyse → UX/UI → Architecture → Développement → Base de données → API → Tests → Déploiement → Maintenance, avec une forte utilisation de l'IA comme outil d'accélération.

Ma philosophie

« Je transforme les idées en expériences numériques. »

« Je conçois et développe des solutions numériques pensées pour le monde réel. »

Ma vision

À moyen et long terme, je veux évoluer de Développeur → Product Builder → Tech Entrepreneur, avec une spécialisation progressive dans le SaaS, les applications web/mobiles, l'IA, l'automatisation et les produits numériques africains.

Mon objectif : ne pas seulement être celui qui exécute du code, mais celui qui comprend le problème → le produit → la technologie → l'utilisateur → le business.
